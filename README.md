## Overview

The Disaster Response and Resource Management System (DRRMS) is a web-based application developed to support disaster management and emergency response activities.

During disasters, effective communication, timely information, and efficient resource allocation are essential. DRRMS aims to address these challenges by providing a centralized platform for managing disaster-related information and coordinating response activities.

The system helps connect citizens, volunteers, and disaster management authorities, enabling better coordination and more organized emergency response.

## Features

- **Disaster Reporting:** Report and manage disaster incidents.
- **Resource Management:** Manage and coordinate emergency resources.
- **Shelter Management:** Maintain shelter-related information.
- **Volunteer Coordination:** Support volunteer registration and coordination.
- **Emergency Response Coordination:** Facilitate communication between disaster response stakeholders.
- **Disaster Information Management:** Centralize relevant disaster-related information.

## Getting Started

Follow these steps to set up the project locally.

### Prerequisites

Make sure the following tools are installed:

- Git
- Node.js and npm
- PHP
- MySQL Server
- Visual Studio Code or another code editor

### 1. Clone the Repository

```bash
git clone https://github.com/ahmedjihan258/DRRMS.git
```

Navigate to the project directory:

```bash
cd DRRMS
```

### 2. Configure the Database

1. Start your MySQL server.
2. Open your MySQL client or database management tool.
3. Locate the database files inside the `database/` directory.
4. Import the provided SQL script into MySQL.
5. Configure the database connection in the backend PHP files using your local database credentials.

### 3. Run the Backend

Navigate to the backend directory:

```bash
cd backend
```

Configure the database connection.

Run the PHP backend using the appropriate local PHP server configuration.

### 4. Run the Frontend

Open a new terminal and navigate to the frontend directory:

```bash
cd frontend
```

Install the required dependencies:

```bash
npm install
```

Start the frontend development server:

```bash
npm run dev
```

If the project uses a different start script, use the command defined in the frontend's `package.json`.
